# 🤖 AI Career & Resume Agent

An AI-powered career assistant that analyzes a user's resume and provides personalized career guidance.

## 📌 Project Overview

AI Career & Resume Agent is a web-based application built using Python and Streamlit.

The application allows users to upload their resume and enter their career information. It analyzes the resume using an LLM and provides suitable job roles, skill gaps, a learning roadmap, and interview preparation suggestions.

## 🎯 Problem Statement

Students and freshers often face difficulty in:

- Understanding which job roles suit their skills
- Identifying missing or weak skills
- Creating a personalized learning roadmap
- Preparing for technical interviews

This project aims to provide these recommendations through an AI-powered application.

## 💡 Features

- 📄 Resume upload
- 🔍 Resume text extraction
- 🤖 AI-powered resume analysis
- 💼 Suitable job role recommendations
- ⚠️ Skill gap identification
- 📚 Personalized learning roadmap
- 🎤 Interview preparation suggestions
- 📖 Career knowledge base
- 🔎 Knowledge retrieval / RAG workflow
